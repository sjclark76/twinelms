# Button

A pill-shaped action, 44px tall so it is easy to tap on a phone. Use `nest-btn` plus one variant: `nest-btn-primary` (lake, the main action), `nest-btn-secondary` (beech), `nest-btn-warm` (clay, only for "Add your home town"-style invitations) or `nest-btn-quiet` (white with a slate outline, for everything else). Add `nest-btn-sm` (36px) inside cards.

Only one deep-filled button per screen; the rest are quiet. Labels are verb first and short, and must translate well: "Copy password", not "Grab it!". Works on `<button>` and `<a>`.
