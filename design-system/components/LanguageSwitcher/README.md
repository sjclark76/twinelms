# LanguageSwitcher

Lets a guest pick their language. Each language is a short chip, never a flag: the two-letter code for languages written in the Latin alphabet ("EN", "DE", "FR") and the language's own name for Chinese, Japanese and Korean ("中文", "日本語", "한국어"), with a `lang` attribute, the language's own name as visually hidden text after the code (so a screen reader hears "DE Deutsch" and a voice-control user can still say "click DE"; never an `aria-label` that drops the visible code) and a link to the same page in that language (e.g. `/de/guide/`). The current one is filled lake with `aria-current="true"`.

The chips (`nest-lang`) are used at every width and are never tucked into the menu, so a guest can always see and change language. On phones they share one row under the wordmark, each 44px tall but only about 28 to 40px wide. That is under our 44px target, but nine languages can't fit one row at 360px otherwise, and keeping them all visible matters more; it still meets WCAG 2.2's 24px minimum target size (2.5.8, AA). On wider screens the chips are 36px tall, for mouse use. Remember the guest's choice in the browser.
