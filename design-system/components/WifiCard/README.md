# WifiCard

Gets a guest online in one step. A QR code in the standard Wi-Fi format (`WIFI:T:WPA;S:<network>;P:<password>;;`) joins the network from an iPhone or Android camera; the network name, password and a "Copy password" button serve guests already reading on their phone, who can't scan their own screen.

The QR is drawn in `ink` on white with a quiet zone, never in a brand colour, so every phone can read it. Print the same card for the room.
