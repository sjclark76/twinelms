# Tag

A pale pill that says what kind of thing a card is about, so guests can scan the guide. Variants map to the activity colours: `nest-tag-hike` (meadow), `nest-tag-bike` (oat, also eateries), `nest-tag-lake` (lake-tint, also skiing), `nest-tag-river` (river), `nest-tag-animal` (tussock) and plain mist for facts like "Open 7 days" (`nest-tag-plain` hides the dot).

Text is always ink; the word carries the meaning, the colour only helps. One to three tags per card.
