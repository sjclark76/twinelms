# SiteFooter

The beech-green band at the bottom of every page, in three columns: the name and address, how to contact the hosts, and emergency information. Underneath a hairline sits the house reminder (no smoking) and the review request.

Use `nest-container` for the inner width and `nest-footer-grid` for the columns, which stack on phones. Phone numbers are `tel:` links; names, addresses and numbers are never translated. All text is white on beech (5.9:1).
