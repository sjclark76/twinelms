# GalleryTile

One photo in the gallery grid: 4:3, `radius-md` corners, with an optional short caption on a white pill. Add `wide` to let a hero photo span two columns. Tapping a tile opens the full photo in a lightbox.

The consumer provides the image (optimised, with alt text in every language) and the caption. The coloured tiles in the preview stand in until real photos exist.
